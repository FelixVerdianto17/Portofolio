# Project Brief — Cinematic Portfolio Opening

## Project Name

Cinematic Personal Portfolio Opening

## Owner

Felix Verdianto Herman

## Role

Web Developer

## Positioning

Felix Verdianto Herman is a Web Developer focused on building clean, interactive, and modern web experiences, with frontend strength and backend fundamentals using Node.js, Express, API flow, and basic database concepts.

## Main Goal

Build a high-end cinematic opening experience for a personal portfolio website using React Vite.

The website should be inspired by premium creative developer portfolios, but it must not copy any website 1:1.

## Tech Stack

* React
* Vite
* TypeScript
* Tailwind CSS
* Motion
* Lenis
* HTML5 Canvas

## Main Scope for Version 1

Only build:

1. Animated preloader
2. Scroll-linked image sequence hero section (opening section only)
3. Cinematic text overlays during scroll
4. TextRevealIntro section (after SequenceHero)

## Do Not Build Yet

Do not build these in version 1:

* Projects section
* About section
* Services section
* Testimonials
* Contact section
* Footer
* Blog
* AI chatbot
* Full portfolio pages

## Asset Source

Use existing sequence images from:

/public/sequence/

Do not use external images.
Do not generate new images.
Do not use Unsplash.
Do not replace the provided sequence assets.

## Visual Direction

* Dark background
* Cinematic
* Premium
* Minimal
* Smooth motion
* Large typography
* Clean composition
* High contrast
* Awwwards-inspired, but original

## Background Color

Use black as the base background:

#000000

## Main Experience

When the user opens the website:

1. A preloader appears first.
2. The loading percentage animates from 0 to 100.
3. The name and role are revealed.
4. The preloader exits smoothly.
5. The hero section appears.
6. As the user scrolls, the image sequence is scrubbed through canvas.
7. Text overlays fade in and out based on scroll progress.
8. After the sequence hero, the TextRevealIntro section smoothly reveals text word-by-word on scroll.
